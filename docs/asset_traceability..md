# Asset traceability document for CustomerServiceSimulator

This document is an exhaustive compendium of all third party assets used as part of this project.

## Format and contents

Contents (assets) are sorted by the feature(s) they're used in. If present in multiple features
 an asset will be listed under the last tag/system common to all relevant features.  
Any asset listed includes:
- In-project name
- Author's name
- Where it was sourced from
- License
- Modifications (if any)

## Potential Mistakes

If any asset reference is incorrect, incomplete or missing entirely please contact the repo owner
 so it can be corrected as soon as possible.

Some assets have been inherited from a previous project but have been impossible to trace back
 to an original author, due to time constraints they might be used as placeholders until a proper
 replacement is found or produced, in such cases they will be tagged as such; we apologise for any
 inconvenience this might cause.  
Entries for any asset internally made for this project should not be expected,
 don't regard their absence as a mistake. If you're intrested in any asset of this kind please
 contact the repo owner for further details.
